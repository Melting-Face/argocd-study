# 위키 발행 규약

> 이 문서는 `../dagster-study` `docs/conventions/publishing.md`(17.8KB)에서 **§4-1 위키
> 산출물 규약만** 이식한 것이다. 원본 §1~3(DUA·소규모 셀(<5) 마스킹 등 데이터 거버넌스),
> §4(`docs/posts/**` 공개 원고), §5~7(`security` 서브에이전트 컨펌 게이트)은 **이 저장소에
> 해당 데이터·에이전트가 없어** 이식하지 않았다. `wiki/` 디렉터리 구조·고정 파일·평평 구조
> 요구는 [설계 문서](../superpowers/specs/2026-10-04-argocd-study-design.md) §11에도 있다 —
> 여기서는 **왜 그 규칙인지**(함정과 근거)를 적고 중복하지 않는다.

## 왜 위키가 별도 규약인가

**GitHub 위키는 저장소와 다른 매체다.** `main`에 push되면 `.github/workflows/wiki.yml`이
`wiki/`를 GitHub 위키로 **단방향 미러**한다. 미러는 배달이지 승인이 아니므로, 커밋 시점에
이미 "발행"과 같은 무게를 갖는다 — 저장소가 공개이므로 더 그렇다(`docs/conventions/git.md`
§5 "커밋이 곧 발행").

## 경로·명명 규약

- 경로는 **`wiki/<slug>.md`** — **평평하게** 둔다. 위키에는 계층 사이드바가 없어 하위
  디렉터리를 만들면 탐색이 오히려 나빠진다. 기계 강제는
  [`scripts/doc_lint.py`](../../scripts/doc_lint.py)의 `check_wiki_flat()`가 한다
  (하위 디렉터리 `.md`는 FAIL).
- 파일명은 **영문 kebab-case**(URL에 그대로 노출), 제목(H1)은 한국어.
- 고정 이름 둘: **`Home.md`**(랜딩)·**`_Sidebar.md`**(사이드바). 새 노트를 추가하면
  **두 인덱스 모두에** 링크를 추가한다 — `doc-links` pre-commit 훅이 미등재 노트를 잡는다.
- **`wiki/README.md`를 두지 않는다** — 미러되면 `README`라는 엉뚱한 페이지가 위키에 생긴다.
- **프론트매터를 쓰지 않는다** — 위키는 YAML 프론트매터를 렌더링하지 못하고 본문 맨 위에
  그대로 노출한다.

## 예시와 함께 정리한다

**위키 노트는 예시(실사용 위주)와 함께 정리한다.** 주장·함정·교훈을 서술로만 두지 않고,
그것을 드러내는 **명령·설정·에러 원문**을 그 자리에 함께 둔다. 판정 명령에는 무엇이 나와야
통과인지를 주석으로 단다.

**「실사용」의 경계** — 넓히면 이 규칙이 거짓 예시를 부른다.

- 인용 대상은 **저장소에 실재하는 선언**(Application YAML·Helm chart·Terraform HCL)과
  실측으로 기록된 값·에러 메시지다.
- 🔴 **관측되지 않은 실행 출력을 예시로 만들지 않는다.** 명령·출력을 지어내 예시처럼
  보이게 두면, 되돌릴 수 없는 매체(위키)에 거짓이 남는다. 이것이 [설계 문서](../superpowers/specs/2026-10-04-argocd-study-design.md)
  §6의 "기대 출력 예시는 비워 둔다" 규율과 같은 원칙이다.
- **관측이 없으면 명령까지만 쓰고 기대 출력을 비운다.**
- 인용 출처가 저장소 파일이면 저장소 상대경로를 본문에 밝힌다.

## 링크 표기

저장소 원본에는 **`.md`를 붙여** 쓰고, 미러 단계에서
[`scripts/wiki_linkify.py`](../../scripts/wiki_linkify.py)가 접미어를 뗀다.

```text
저장소 원본:  [텍스트](other-page.md)     ← 실파일이라 doc_lint --links 가 검사한다
미러 결과  :  [텍스트](other-page)        ← 확장자가 붙으면 위키에서 404다
```

🔴 **원본에서 확장자를 생략하지 않는다.** 그렇게 하면 링크 검사기가 대상을 못 찾아 검사가
통째로 죽는다. 같은 이유로 **참조형 링크(`[x]: url`)와 HTML `<a href>`는 쓰지 않는다**
(`wiki_linkify.py`·`doc_lint.py` 둘 다 인라인 마크다운 링크만 인식한다 — 변환·검사 대상 밖).

## 게이트는 커밋 시점이다

```
작성(wiki/**)  →  사용자 확인  →  커밋·푸시  →  기계가 미러
```

위키는 `main` push 시 자동 미러되므로 "사람이 업로드하는 단계"가 없다 — 게이트가 사라지는
것이 아니라 **커밋 시점으로 앞당겨진다.** 🔴 **`wiki/**` 커밋 전에 내용을 사용자가 확인한다**
— 저장소가 공개라 커밋이 곧 공개이고, 위키는 회수 지점이 하나 더 늘어난다(저장소 이력 +
위키 저장소 이력 둘 다 남는다).
